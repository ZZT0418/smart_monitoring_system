智能环境监测与安防系统的终端代码文件：
1.项目概述：基于STM32F103C8T6与FreeRTOS构建多任务系统，采集光照、温度及红外信号，实时显示在OLED屏，设置阈值实现分级报警并联动直流电机风扇降温；
           通过ESP32作为网络协处理器，与STM32进行串口通信，并通过设计自定义串口协议，将数据以JSON格式通过MQTT上报至OneNET平台，支持远程指令控制。
2.成果：解决了裸机架构下多任务耦合度高、实时性差的问题；通过队列与互斥锁实现任务间数据同步与资源共享，避免数据竞争；
        利用一阶指数滤波抑制传感器数据跳变，采集误差≤5%；通过MQTT实现环境数据云端可视化与远程控制，报警响应延迟控制在2-3s，远程控制成功率>98%。
        考虑到实际应用场景，进行了简单的低功耗设计，如下：高功耗的来源主要是OLED显示屏，通过设计超时时间即无操作n秒后实现自动熄屏，通过按键中断唤醒；
        串口接收数据也通过中断来实现，避免轮询数据信息带来的消耗；在确保各模块功能正常运行的条件下，尽可能降低系统频率来减少能耗，如默认72MHZ主频降低至32MHZ或24MHZ.
